# 🍿 Tickitz Movie Frontend

A **React.js** frontend for **Tickitz Movie**.  
This app consumes the Tickitz Movie API and provides a modern, responsive interface for browsing movies, booking tickets, and managing orders.

---

## 🛠 Tech Stack

* **React.js** – Build dynamic and interactive user interfaces  
* **Redux Toolkit** – Efficiently manage and centralize application state  
* **React Router** – Enable seamless navigation between pages and views  
* **TailwindCSS** – Utility-first CSS framework for fast and responsive styling  

---

## 🌐 Environment Variables

```env
VITE_API_URL=http://localhost:6011
````

---

## ⚡ Installation

1. **Clone the repository**

```bash
git clone git@github.com:metgag/metgag-loket-tickitz.git
```

2. **Navigate to the project directory**

```bash
cd metgag-loket-tickitz
```

3. **Install dependencies**

```bash
npm ci
```

4. **Set up environment variables**
   Create a `.env` file with the necessary variables.

5. **Run the project**

```bash
npm run dev
```
